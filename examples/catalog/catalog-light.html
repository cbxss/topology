Topology · components

Every node kind, and every pattern in kit/patterns.mjs, in iso and 2D. A kind goes in a spec as a node; a pattern is a function that returns a fragment of nodes, edges and groups, which compose() joins into a spec and link() wires to the rest. Each pattern figure below is built from the code under it.

Node kinds

client

A user or a caller: a laptop. Usually a source, with emit.

{ id: "…", kind: "client" }

lb

A load balancer: round-robins over healthy targets, noticing a dead one after detect seconds.

{ id: "…", kind: "lb" }

gateway

An API gateway: round-robin like an LB; with capacity it sheds the excess (429s).

{ id: "…", kind: "gateway", capacity: 12 }

service

A stack of 1U servers, one per replica (up to 4), each with its own LED.

{ id: "…", kind: "service", replicas: 3 }

worker

A background worker: a service with a fan on top. Consumes from logs and queues.

{ id: "…", kind: "worker", replicas: 2 }

cache

Memory chips on a board. Cache-aside: callers check it first, misses go on (p).

{ id: "…", kind: "cache" }

db

Stacked disks with a role on top. Replicas follow through replication edges.

{ id: "…", kind: "db", role: "primary" }

storage

Object storage: a bucket of disks, wider at the top.

{ id: "…", kind: "storage" }

kafka

A topic: one lane of record cells per partition, a cursor per consumer group; with brokers, clickable broker units.

{ id: "…", kind: "kafka", partitions: 3, brokers: 3 }

queue

A queue: one lane; its consumers compete for messages.

{ id: "…", kind: "queue" }

cdn

An edge PoP with a globe: serves hit, sends misses to its origin.

{ id: "…", kind: "cdn", hit: 0.9 }

dns

A DNS tower: routes like an LB, but clients keep stale answers for ttl seconds.

{ id: "…", kind: "dns", ttl: 30 }

external

A third-party API, outlined dashed. Give it a realistic ms.

{ id: "…", kind: "external", ms: 300 }

scheduler

A clock: emits burst requests every every seconds.

{ id: "…", kind: "scheduler", emit: { every: 5, burst: 10 } }

flags

A flag service: one switch per flag, its knob at the rollout. Drives flag/unless edges.

{ id: "flagd", kind: "flags" }

box

Anything else: a plain block.

{ id: "…", kind: "box" }

service + sidecar

Any service with sidecar: true: a proxy box on its side that adds sidecarMs.

{ id: "…", kind: "service", replicas: 2, sidecar: true }

service + buffer

With capacity and queue, a buffer of cells on top fills (amber) when it's over capacity.

{ id: "…", kind: "service", replicas: 2, capacity: 10, queue: 6 }

Patterns

kafkaTopic

A topic and its consumer groups, each consumer a worker, wired with its group.

compose({},
  { nodes: [{ id: "api", kind: "service", emit: 10 }] },
  kafkaTopic("orders", {
    partitions: 6,
    groups: { billing: { consumers: 2, rate: 8 }, search: { consumers: 1, rate: 20 } },
  }),
  link("api", "orders"),
)

region

Load balancer → API → database on a region plate, with an optional cache in front and a replica behind. in is the LB, out the API.

compose({},
  { nodes: [{ id: "users", kind: "client", emit: 12 }] },
  region("us", { label: "us-east-1", cache: { hit: 0.85 }, replica: true }),
  link("users", "us-lb"),
)

cacheAside

Every request checks the cache; the misses (1 − hit) go to the database.

compose({},
  { nodes: [{ id: "users", kind: "client", emit: 10 },
            { id: "api", kind: "service" }, { id: "pg", kind: "db" }] },
  link("users", "api"),
  cacheAside("api", { db: "pg", hit: 0.9 }),
)

replicatedDb

A primary and its streaming replicas.

compose({},
  { nodes: [{ id: "api", kind: "service", emit: 8 }] },
  replicatedDb("pg", { replicas: 2 }),
  link("api", "pg"),
)

queueWorkers

A queue and the workers competing for it.

compose({},
  { nodes: [{ id: "api", kind: "service", emit: 15 }] },
  queueWorkers("jobs", { workers: 3, rate: 6 }),
  link("api", "jobs"),
)

canary

A router splits traffic by a feature flag, pushed from a flag service. out is [v1, v2].

compose({},
  { nodes: [{ id: "users", kind: "client", emit: 12 },
            { id: "lb", kind: "lb", route: "all" }] },
  link("users", "lb"),
  canary("checkout", { router: "lb", rollout: 0.25 }),
)
